# 项目经历

这里记录正在完成和持续迭代的实践项目。每个项目都会围绕真实需求展开，并补充架构、数据设计、接口实现和问题复盘。

## 校园服务平台

**项目状态：学习项目 · 持续开发**

面向校园场景的服务管理平台，计划覆盖用户、内容和服务预约等基础功能。项目重点是练习从需求拆分到接口落地的完整后端开发流程。

- **后端技术**：Java、Spring Boot、Spring MVC
- **数据与缓存**：MySQL、Redis
- **工程工具**：Maven、Git、Docker
- **计划模块**：用户认证、角色权限、内容管理、服务预约、操作日志
- **重点实践**：数据库建模、统一返回体、参数校验、全局异常处理和分页查询

### 当前进度

- 已完成项目边界和核心模块拆分
- 正在设计用户、角色、内容和预约相关的数据表
- 后续补充接口文档、测试用例与部署记录

- **使用技术**：Hexo、Fluid、Markdown、Stylus

- **维护内容**：Java 后端、数据库、算法和计算机基础笔记

## 项目记录原则

我会优先记录真实完成的工作，包括具体负责内容、遇到的问题、方案取舍和可以改进的地方，不用尚未实现的功能包装项目经历。
