# 关于我

你好，我是 **陈建扬**，一名计算机专业学生，正在准备 Java 后端开发方向的实习与校招。

我喜欢把抽象的知识放进可运行的代码里：先理解原理，再通过小项目验证，最后整理成可以复用的笔记。这个博客就是我的学习记录，也是一份持续更新的技术简历。

## 关注方向

- **Java 后端**：Java 基础、集合、并发、异常处理与面向对象设计
- **Web 开发**：Spring Boot、RESTful API、参数校验与统一异常处理
- **数据存储**：MySQL 表结构设计、索引、事务，以及 Redis 的常见使用场景
- **工程实践**：Git、Linux、Docker、接口文档和基础的自动化测试
- **计算机基础**：数据结构与算法、计算机网络、操作系统

## 学习方式

我会把一个问题拆成四个部分来记录：**问题是什么、原理如何工作、代码怎样实现、有哪些边界和陷阱**。比起只记结论，我更在意能否解释清楚并在新场景中使用。

## 当前目标

1. 完成一个结构清晰、可部署的 Spring Boot 项目。
2. 系统复习 Java、MySQL、Redis 和计算机基础。
3. 保持稳定输出，把学习过程沉淀为可检索的技术文章。
